# Frequently Asked Questions

Common questions about Duplicate Asset Detector Pro.

## Does detection rely only on asset names?

No. The documentation describes content-based duplicate detection; see [Smart Detection](/duplicate-asset-detector/features#smart-detection).

## Should I back up before cleanup?

Yes. Back up your project and review every change before removing assets.

## What is Redirect & Delete?

The operation is designed to consolidate references before deletion. Review the [cleanup guide](/duplicate-asset-detector/usage#step-5-clean-up-duplicates) carefully.
