# Troubleshooting

Common issues and checks for Duplicate Asset Detector Pro. For setup instructions, see [Installation](/duplicate-asset-detector/installation).

## An asset is currently in use

Close any open levels that reference the asset before deleting duplicates. Review references before retrying.

For more details, read the [related guide](/duplicate-asset-detector/usage).

## A potential false positive was found

Do not delete the asset. Review the pair and report the affected types and scan details to support.

For more details, read the [related guide](/duplicate-asset-detector/features).

## A scan is slow

Limit the scan to a folder or asset type and exclude unnecessary Engine or Plugin content.

For more details, read the [related guide](/duplicate-asset-detector/usage).

## Still Need Help?

Contact [Deblx Support](/support) with your Unreal Engine version, plugin version, a description of the issue and any related logs.
