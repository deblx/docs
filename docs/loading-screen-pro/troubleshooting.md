# Troubleshooting

Common issues and checks for Loading Screen Pro. For setup instructions, see [Installation](/loading-screen-pro/installation).

## Loading screen does not appear

Check that a loading screen Data Asset is assigned in Project Settings. Verify behavior in a packaged build or Launch, not only Play-in-Editor.

For more details, read the [related guide](/loading-screen-pro/usage).

## Progress bar stays at 0%

Review the loading screen configuration and minimum display time. Automatic loading may finish before a visible update can occur.

For more details, read the [related guide](/loading-screen-pro/usage).

## Background music does not play

Use the Data Asset preview or a packaged build to check audio playback.

For more details, read the [related guide](/loading-screen-pro/features).

## Slideshow images are missing

Check that the assigned assets are compatible Texture2D images and are present in the configured Media Sequence.

For more details, read the [related guide](/loading-screen-pro/features).

## Still Need Help?

Contact [Deblx Support](/support) with your Unreal Engine version, plugin version, a description of the issue and any related logs.
