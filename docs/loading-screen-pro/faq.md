# Frequently Asked Questions

Common questions about Loading Screen Pro.

## Do I need C++ to get started?

No. The default loading screen is configured through a Data Asset and Project Settings.

## Can I use different loading screens per level?

Yes. See the [per-level override instructions](/loading-screen-pro/usage#per-level-loading-screens).

## Can Blueprints control the loading screen?

Yes. See the [Blueprint Integration guide](/loading-screen-pro/usage#blueprint-integration).
