# Contributing to the Documentation

The documentation is maintained in the public [deblx/docs](https://github.com/deblx/docs) repository. Product instructions are written in Markdown.

## Suggest a Change

1. Open the documentation article you want to improve.
2. Select **Edit this page on GitHub** near the end of the article.
3. Edit the Markdown source in GitHub.
4. Propose the changes through a pull request.
5. Explain what changed and which Unreal Engine or plugin version the correction applies to.

If you prefer not to edit GitHub files, contact the [Deblx Help Center](https://deblx.com/help).

## Documentation Guidelines

- Use concise, practical steps and correct menu names.
- Keep product names, version requirements and file paths accurate.
- Link to relevant product guides rather than duplicating instructions.
- Avoid unverified claims about compatibility, performance or privacy.
- Remove personal data, tokens and private project paths from logs or screenshots.
- Place screenshots in the repository only when publication is permitted.

## Review and Publishing

Proposed changes are reviewed before being merged into the main branch. The documentation preview updates automatically from the migration branch. Once the migration is complete, changes merged into `main` will build and publish automatically through GitHub Actions.
