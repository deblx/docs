# Features

Asset Size Analyzer helps inspect the disk size and estimated memory use of Unreal Engine assets.

## Asset Scanning

Scan an entire project or focus on individual folders. Results include asset name, type, path and size information.

See [Scanning Options](/asset-size-analyzer/usage#scanning-options).

## Filtering & Sorting

Use the asset-type filter, minimum-size threshold and search field to narrow down results. Sort the results table by size and other columns.

See [Filtering Assets](/asset-size-analyzer/usage#filtering-assets).

## Disk and Memory Information

The analyzer displays file size and estimated memory footprint. Memory size is an estimate and may differ from runtime values.

## CSV Export

Export analysis results for reporting and team reviews.

See [Exporting Data](/asset-size-analyzer/usage#exporting-data).

## Workflow Integration

Use the tool for project audits, investigating oversized assets, and planning performance improvements.

For practical examples, see the [Usage Guide](/asset-size-analyzer/usage).
