# Frequently Asked Questions

Common questions about Asset Size Analyzer.

## Can I scan just one folder?

Yes. See [Scanning Options](/asset-size-analyzer/usage#scanning-options).

## Can I export scan results?

Yes. The tool supports [CSV export](/asset-size-analyzer/usage#csv-export).

## Can I sort assets by size?

Yes. Use the table column headers for sorting; see [Understanding the Interface](/asset-size-analyzer/usage#understanding-the-interface).
