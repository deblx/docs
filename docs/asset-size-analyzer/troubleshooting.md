# Troubleshooting

Common issues and checks for Asset Size Analyzer. For setup instructions, see [Installation](/asset-size-analyzer/installation).

## Scanning takes too long

Scan a smaller folder or narrow the asset filter to reduce the scope.

For more details, read the [related guide](/asset-size-analyzer/usage).

## An asset is not visible

Reset the minimum size threshold, select all asset types and clear the search filter.

For more details, read the [related guide](/asset-size-analyzer/usage).

## Memory size differs from runtime usage

Memory figures are estimates; actual usage depends on compression, streaming and engine settings.

For more details, read the [related guide](/asset-size-analyzer/usage).

## Still Need Help?

Contact [Deblx Support](/support) with your Unreal Engine version, plugin version, a description of the issue and any related logs.
