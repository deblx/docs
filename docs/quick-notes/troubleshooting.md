# Troubleshooting

Common issues and checks for Quick Notes / ToDo. For setup instructions, see [Installation](/quick-notes/installation).

## A note does not appear

If Editor Only is enabled, exit Play-in-Editor to view editor notes.

For more details, read the [related guide](/quick-notes/usage).

## A note seems to be missing

Clear the Overview Panel filters, search by title and check whether resolved notes are hidden.

For more details, read the [related guide](/quick-notes/usage).

## A Blueprint node was removed

Open the Overview Panel to review notes whose original nodes no longer exist.

For more details, read the [related guide](/quick-notes/usage).

## A QN error code appears

Record the QN-xxx identifier from the Output Log and include it in a support request.

For more details, read the [related guide](/quick-notes/features).

## Still Need Help?

Contact [Deblx Support](/support) with your Unreal Engine version, plugin version, a description of the issue and any related logs.
