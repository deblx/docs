# Frequently Asked Questions

Common questions about Quick Notes / ToDo.

## Are notes included in packaged builds?

Quick Notes is an editor-only plugin and does not add functionality to packaged games.

## Can I attach notes to Blueprint nodes?

Yes. The [usage guide](/quick-notes/usage#creating-your-first-blueprint-note) explains how.

## Can I export notes?

Yes. The Overview Panel includes a text export option, described in the [Features guide](/quick-notes/features#export-functionality).
