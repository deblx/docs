# Compatibility

Plugin compatibility depends on the product version and the Unreal Engine release. The [Fab Marketplace](https://www.fab.com/de/sellers/Deblx) listing is the source for currently supported versions.

## Installation

1. Locate your plugin in the Fab Library in the Epic Games Launcher.
2. Choose **Install to Engine** and select an available engine version.
3. Open your Unreal Engine project, then enable the plugin under **Edit → Plugins**.
4. Restart the editor if requested.

## Plugin Types

**Editor-only:** Quick Notes / ToDo, Duplicate Asset Detector Pro and Asset Size Analyzer focus on workflows inside the Unreal Editor.

**Runtime and editor:** Loading Screen Pro provides runtime loading visuals along with editor configuration and preview features.

## Updating Plugins

Review the [Deblx Changelog](https://changelog.deblx.com) for release announcements. If a documented step differs from what you see, include your plugin and engine versions when contacting [Support](/support).
