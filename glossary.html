Documentation/Glossary

Glossary ​

Asset ​

A resource managed by Unreal Engine, such as a texture, material, mesh, audio file or Blueprint.

Blueprint ​

Unreal Engine's visual scripting system.

Content Browser ​

The editor interface for managing project assets and folders.

Data Asset ​

An Unreal Engine asset that stores editable configuration data. Loading Screen Pro uses Data Assets for its settings.

Editor-Only Plugin ​

A plugin designed for editor workflows instead of packaged game functionality.

Package / Packaged Build ​

A built distribution of your project. Runtime features can behave differently in packaged builds and Play-in-Editor.

PIE (Play-in-Editor) ​

Testing a project within the Unreal Editor.

Referencer ​

An object or asset that references another asset. This information is important when reviewing duplicate cleanup operations.

Redirector ​

An Unreal Engine mechanism for preserving references to moved or consolidated assets.

Runtime Memory Estimate ​

An approximation of memory used by an asset at runtime. Actual usage varies with engine settings, compression and streaming.
